# AyuLM Training Plan

## Objective
Train an original language model using randomly initialized weights.

## Stage 1 — Environment
- Set up Python
- Install PyTorch
- Verify CPU/GPU availability

## Stage 2 — Tokenizer
- Study tokenization
- Build a tokenizer
- Test text encoding and decoding

## Stage 3 — Dataset
- Identify properly licensed text datasets
- Clean and preprocess text
- Create training and validation splits

## Stage 4 — Model
- Implement a decoder-only Transformer
- Initialize weights randomly
- Count and document parameters

## Stage 5 — Training
- Implement next-token prediction
- Calculate training loss
- Save checkpoints
- Support resuming interrupted training

## Stage 6 — Evaluation
- Measure validation loss
- Test text generation
- Record model limitations

## Stage 7 — Scaling
- Conduct controlled scaling experiments
- Measure compute and memory requirements
- Research distributed training

## Long-Term Target
Research a path toward a 100B-parameter model.

## Budget
Use free resources wherever feasible. No paid APIs or infrastructure.
